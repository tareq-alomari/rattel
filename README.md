**رتّل** هو تطبيق إسلامي شامل يهدف إلى تسهيل حفظ ومراجعة القرآن الكريم، وتوفير أدوات تعليمية متكاملة للطلاب والمعلمين في الحلقات القرآنية.

---

لقد قمنا بإعداد توثيق شامل للمشروع لمساعدتك على فهم كل جزء منه:

- **[1. نظرة عامة وهيكلية المشروع (Project Overview)](docs/01_Project_Overview.md)**  
  تعرف على التقنيات المستخدمة، هيكل المجلدات، والخدمات الأساسية.

- **[2. دليل المستخدم الشامل (User Guide)](docs/02_User_Guide.md)**  
  شرح تفصيلي لكل شاشة في التطبيق، من تسجيل الدخول إلى استخدام ميزات القرآن المتقدمة.

- **[3. دليل المطور (Developer Guide)](docs/03_Developer_Guide.md)**  
  معلومات تقنية للمطورين حول إضافة الملفات، قواعد البيانات، وبناء النسخ.

## ✨ المميزات الرئيسية
- 📖 **قارئ قرآن متعدد الأنماط**: نص، صور (مصحف المدينة)، وملفات PDF.
- 🎧 **مشغل صوتي متطور**: تلاوات مع خيارات التكرار للحفظ.
- 🎓 **نظام تعليمي**: واجهات خاصة للطالب والمعلم لإدارة الحلقات.
- 🏆 **نظام تحفيز (Gamification)**: نقاط وشارات لتشجيع الحفظ.
- 📚 **مكتبة إسلامية**: أحاديث، أذكار، وتفسير.

## 🚀 البدء (Quick Start)

1. تأكد من تثبيت **Flutter SDK**.
2. قم بتحميل المكتبات:
   ```bash
   flutter pub get
   ```
3. شغل التطبيق:
   ```bash
   flutter run
   ```

## 📝 ملاحظات هامة
- تأكد من وجود ملف قاعدة البيانات في `assets/data/` قبل التشغيل.
- التطبيق يدعم الوضعين المضيء والليلي (Light/Dark Mode).
