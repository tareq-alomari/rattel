# رتّل 📖

تطبيق متكامل لحفظ ومراجعة القرآن الكريم مع نظام تقييم للمعلمين.

## المميزات ✨

### للطلاب 👨‍🎓
- 📚 **قارئ القرآن** - عرض القرآن بخط عثماني احترافي
- 🔍 **البحث** - البحث في آيات القرآن الكريم
- 📊 **تتبع التقدم** - متابعة الآيات المحفوظة والأيام المتتالية
- 🏆 **نظام الشارات** - إنجازات ومكافآت للتحفيز
- ⚙️ **الإعدادات** - اللغة، المظهر، الإشعارات

### للمعلمين 👨‍🏫
- 📋 **لوحة التحكم** - إحصائيات شاملة
- 👥 **إدارة الطلاب** - عرض وتتبع جميع الطلاب
- ✅ **نظام التقييم** - تقييم حفظ الطلاب بالدرجات والملاحظات

## التقنيات المستخدمة 🛠️

| التقنية | الاستخدام |
|---------|----------|
| Flutter | إطار العمل الأساسي |
| GetX | إدارة الحالة والتوجيه |
| SQLite | قاعدة البيانات المحلية |
| SharedPreferences | تخزين الجلسات |
| Google Fonts | الخطوط (Cairo, Amiri) |

## هيكل المشروع 📁

```
lib/
├── main.dart                    # نقطة الدخول
└── app/
    ├── core/
    │   ├── theme/               # المظهر والألوان
    │   └── translations/        # الترجمات (عربي/إنجليزي)
    ├── data/
    │   ├── models/              # نماذج البيانات
    │   ├── providers/           # قاعدة البيانات
    │   └── services/            # الخدمات
    ├── modules/
    │   ├── auth/                # تسجيل الدخول/الخروج
    │   ├── student/             # واجهات الطالب
    │   ├── teacher/             # واجهات المعلم
    │   ├── quran/               # قارئ القرآن
    │   ├── search/              # البحث
    │   └── settings/            # الإعدادات
    └── routes/                  # التوجيه
```

## التثبيت والتشغيل 🚀

### المتطلبات
- Flutter SDK (3.10+)
- Dart SDK
- Android Studio / VS Code

### خطوات التثبيت

```bash
# 1. استنساخ المشروع
git clone <repository-url>
cd rattel

# 2. تثبيت التبعيات
flutter pub get

# 3. تشغيل التطبيق
flutter run
```

## قاعدة البيانات 💾
